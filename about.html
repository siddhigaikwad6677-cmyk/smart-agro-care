About Our Project

Project Overview

Smart Agro Care is an intelligent farming website developed to help farmers improve crop production. It provides soil quality analysis, crop disease detection, and fertilizer recommendations using modern technology.

Our Objectives

  • 🌾 Detect crop diseases quickly.
  • 🌱 Analyze soil quality.
  • 🧪 Recommend suitable fertilizers.
  • 📱 Help farmers through an easy-to-use website.
  • 🌍 Promote smart and sustainable farming.

Key Features

  • ✔ Soil Testing
  • ✔ Crop Disease Detection
  • ✔ Fertilizer Recommendation
  • ✔ Farmer Login & Signup
  • ✔ Responsive Design
